📌 这是什么

我是 西西弗斯（X：@XiaoHan_aw）。 2026 年 4 月，我的本金只有 1 万元；如今交易所 + 券商本金共 2.7 万。我给自己立了一个三年之约： 借助比特币四年周期的确定性，在 2029 年前把 2.7 万滚到 100 万。

这个页面就是契约本身——每一笔交易，无论盈亏，都会如实出现在这里。我会一步一步滚动自己的石头，直至到达山顶。

🔒 数据如何保证真实

  • 全部数据通过 Bitget 官方 API（统一交易账户 v3）自动抓取，非手工填写；
  • API 密钥为只读权限——无交易、无提现权限，仅能查询；
  • 数据由程序定时同步，每次变动都在 GitHub 仓库留有提交记录，可追溯、无法悄悄篡改；
  • 页面上的每一个数字，都可以对照 Bitget App 核验。

ℹ️ 说明

  • 平仓历史：Bitget API 保留约 90 天记录，本站自 2026-08-23 起持续同步留痕；
  • 净盈亏 = 毛盈亏 − 手续费 ± 资金费，口径与交易所一致；
  • 页面仅统计 Bitget 统一账户（含 USDT 本位合约与现货），券商部分不在此列。
